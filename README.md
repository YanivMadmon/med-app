# MedApp — Medication Management for Elderly

A mobile application that helps elderly users manage their medications, while giving family members and caregivers real-time visibility and control.

## The Problem
- Seniors forget to take medications or take double doses
- Existing apps are too complex for elderly users
- Family members have no real-time awareness when a dose is missed
- No Hebrew-first solution exists in the market

## The Solution
A two-sided app:
- **Elderly user** — sees a simple, large-button interface with voice reminders
- **Caregiver (child/family)** — manages medications remotely and receives alerts if a dose is missed
